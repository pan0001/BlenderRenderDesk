# v3.3.1 — 一键接管实时步骤提示

点击“一键接管”后，界面底部显示持续更新的小提示：

1. 检查进程与启动参数。
2. 读取 Blender 工程。
3. 识别脚本、帧范围与输出配置。
4. 加入队列并核对已有帧。

提示来自后台实际处理阶段，附带本次等待时间，不显示虚构百分比。扫描线程繁忙时显示等待；大工程扫描期间保持可见，并说明原 Blender 继续渲染。切换页面仍可查看，不阻塞其他任务操作。

完成后显示成功结果，8 秒后自动收起；失败时保留阶段和具体原因，可手动关闭。多个进程同时接管时按 PID 分别显示；重复点击仍合并为同一后台操作。刷新整个网页后不会恢复这次浏览器的临时提示，任务状态仍可在队列和本机进程中确认。

## 验证

- 58 项后端/API 测试通过，包含识别中的阶段查询、重复请求共享进度、失败保留阶段与错误、未授权访问拒绝。
- 真实 Blender 隔离测试通过：接管完成阶段为第 4 步，原进程保持运行，帧范围识别、按帧暂停和续渲染正常。
- 隔离浏览器演示验证两个进程的独立提示、阶段切换、用时更新、成功 8 秒后收起、失败保留与关闭、切换页面保留；未发现浏览器错误。
- Windows 打包程序原生窗口启动、就绪，以及启动清理已完成记录并保留图片验证通过。

## 升级

关闭旧管理器，完整解压 `BlenderRenderDesk-v3.3.1-Windows.zip` 后运行 `BlenderRenderDesk.exe`，保留 `_internal` 文件夹。默认沿用原数据目录；此前使用 `--data-dir` 时继续指定相同目录。原 Blender 渲染不会因为关闭管理器而退出。

自动接管的脚本支持范围与 v3.3.0 相同。
