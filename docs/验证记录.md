# 3.0 验证记录

环境：Windows、Python 3.13、Blender 5.1.2，2026-09-23。

- 16 项原渲染引擎测试：任务保存、旧任务导入、帧校验、日志、定时与 PID 身份。
- 新 HTTP / Bark 测试：鉴权、跨来源阻断、资源路径限制、异步操作、多客户端日志游标、密钥脱敏、完成通知去重、重启保留、三次失败重试、实际 HTTP JSON 与错误响应。
- 真实 Blender 集成：定时开始、关闭再打开管理器、按帧暂停、进程退出、续渲染、缺失帧修复；逐帧 PNG 外部脚本接入、首次停止、协作续渲染；已完成图片 SHA256 保持一致。
- pywebview WebView2 桌面启动并加载同一网页，产生 smoke-result.json。
- Edge 无头网页端到端：创建任务、定时、Bark 配置、远程设置、独立客户端密钥登录；两个页面共享任务；1440px 桌面与 390px 手机尺寸无横向溢出、无 JavaScript 运行错误。
- 通知测试使用内存替身及本地 HTTP 接收器，未向用户真实 Bark 手机发送；需要在设置页填写设备地址并发送测试通知。
- assets/ 界面截图使用隔离测试任务，不包含实际用户工作空间。

运行方式见 README；测试均使用临时或隔离数据目录，不控制用户现有渲染。

最终验证：24 项后端 / HTTP / Bark 单元测试全部通过。打包 EXE 的 WebView2 启动检查通过。打包服务器实际完成两帧 Blender 渲染，本地 Bark HTTP 接收端收到恰好一次完成通知，验证执行器资源路径及完整通知流程。
