# v3.2.0 — 队列编辑、删除、排序与状态重置

## 本次更新

- 队列任务支持编辑名称、帧范围、步长、CPU 线程、输出目录及工程自动脚本选项。已有完成帧时可改名，改渲染配置前需先从头重置。
- 支持拖动手柄排序，以及上移、下移、置顶；顺序保存到数据目录，本地和远程使用同一份队列。
- 支持删除任务，只移除队列记录，保留工程、渲染图片和历史日志。删除记录持久保存，旧任务文件不会在下次启动时重新导入。
- 部分完成、全部完成和异常任务均可重置为等待状态。可选择保留完成帧继续，或归档旧帧后从头渲染；重置会清除用时与定时计划。
- 运行中请求重置或删除，会先按帧暂停，等当前帧完整保存并退出 Blender 后执行。
- 完成且进程已退出的任务，在下次启动管理器时自动从队列清理；未完成任务继续保留，图片和日志不会删除。接管进程在管理器关闭期间完成的情况也会检查。
- 重置归档使用持久操作记录，意外退出后可恢复；检测到图片变化或同输出目录仍有任务运行时会停止操作并显示原因。

## 使用与升级

下载 `BlenderRenderDesk-v3.2.0-Windows.zip`，完整解压并运行 `BlenderRenderDesk.exe`，保留 `_internal` 文件夹。先关闭旧管理器，新版继续使用原数据目录；使用过 `--data-dir` 的用户需指定同一路径。

**升级首次启动也会清理旧版本已完成的队列记录。** 工程、图片和日志仍在原位置。没有完成的任务与运行中的 Blender 会保留。

在任务详情中使用“编辑任务 / 置顶 / 上移 / 下移 / 重置状态 / 删除任务”。已完成任务如需再次渲染，请在本次关闭前选择“从头重渲染”；选“保留完成帧”只清除状态和用时，不会重算已有帧。

旧完成帧归档位置：原图片文件夹下的 `.renderdesk-history/任务ID/重置ID/`。只归档本任务确认的主图像帧，不处理其他文件或合成器额外输出。归档保持在原磁盘，不复制大图；重新渲染会另外占用磁盘空间。

排序改变队列显示顺序，不抢占已运行任务，不会自动逐项启动所有任务。接管脚本的输出路径和线程仍由原脚本控制；超出已扫描范围需先重新扫描工程。编辑运行中任务前需按帧暂停。
