# v3.1.0 — 工程自动配置、Watchdog、帧预览与 frpc

## 本次更新

1. **全局 Blender 版本管理**：支持添加多个 Blender 版本、选择默认版本，导入工程不再反复配置程序路径。
2. **自动读取工程配置**：后台扫描 `.blend` 的场景、相机、起止帧、步长、渲染引擎、分辨率、输出格式、位深和路径；默认沿用工程设置，不修改源文件。可主动覆盖本次任务范围或输出目录。
3. **批量导入与拖拽**：桌面支持多选、拖入多个工程；网页支持批量填写渲染电脑上的工程路径。
4. **手动设置访问密钥**：设置页可修改密钥并立即生效，其他设备需要使用新密钥重新连接。
5. **两种 Watchdog**：监测输出文件变化；可选意外退出后的限次自动续渲染。正常暂停不会重启，耗时长的正常帧不会被当作卡死结束。
6. **最新完整帧预览**：任务详情显示最新已保存图像；支持常见图片和 EXR / HDR 缩略图生成。
7. **集成官方 frpc 0.71.0**：提供 frps 地址、端口和 Token 设置，支持启动、停止、日志与随管理器启动；需自行配置 frps 服务器。
8. **修正接管任务总帧数**：接管前读取磁盘工程，分别显示“工程范围”和“本次任务范围”；旧任务可重新扫描，避免 1200 帧工程被默认值误记为 60 帧。

保留 Bark 完成通知、实时资源与日志、定时、按帧暂停和继续。工程扫描在单独工作线程中执行，读取工程时仍可查看和控制其他任务。

## 下载与升级

Windows 下载 `BlenderRenderDesk-v3.1.0-Windows.zip`，完整解压后运行 `BlenderRenderDesk.exe`，保留 `_internal` 文件夹。

升级时先关闭旧管理器，再打开新版。新版继续使用原数据目录；使用过 `--data-dir` 的用户需指定同一路径。关闭管理器不会结束正在运行的 Blender。

外部进程控制目前支持单个 Python 脚本同步输出 PNG 序列。扫描以磁盘工程为准，脚本在内存中修改的输出或范围需核对。视频输出、多视图及任意 Blender 进程的完整接管不在本版支持范围。自动恢复和通知需要管理服务保持运行。
